# Space Dragons

A Unity game project built as part of a Creative Tech module.

## About

Space Dragons is a work-in-progress Unity game. The repo currently contains the first draft of the project, with development ongoing.

## Getting Started

### Prerequisites

- [Unity Hub](https://unity.com/download) (recommended)
- Unity Editor — check the project settings for the version used

### Running the Project

1. Clone the repo:
   ```bash
   git clone https://github.com/Jamesus717/Space-Dragons-git.git
   ```
2. Open Unity Hub and click **Add project from disk**
3. Navigate to the `Space Dragons Draft 1` folder and select it
4. Open the project and hit Play in the Unity Editor
